# Board Game Simulation

## 概要

3×3×3の立体ボード上に、2色の面を持つL字型の駒を配置して得点を競うボードゲーム。

現在のゲームルールおよびゲーム進行はPythonで実装済みであり、本プロジェクトでは以下を行う。

* ゲームルールの検証
* 大量対戦シミュレーション
* 統計的なゲーム性の分析
* 戦略AIの実装
* AI同士の対戦
* 各手・各Phase・勝敗のログ取得

## プレイヤー

プレイヤーは2人。

* `F`
* `G`

先手は `F`。

## 駒

各駒は以下の情報を持つ。

* owner
* color1
* color2
* direction1
* direction2

駒は2つの面を持つL字型の立体として扱う。

色は以下の4種類。

* `R`: 赤
* `B`: 青
* `T`: 透明
* `D`: 黒

現在の実装では、駒の所有者と色は別の概念として扱う。

## ボード

ボードは3×3×3。

座標は以下の順序で扱う。

```text
board[z][y][x]
```

軸は `X`, `Y`, `Z`。

Phaseによって使用可能な層が変化する。

## Phase

ゲームはPhase 1〜3から構成される。

* Phase 1では第1層のみ使用
* Phase 2では第2層を使用
* Phase 3では第3層を使用

Phaseの進行・終了条件については `SPEC.md` の記述および現在のゲーム実装を正とする。

各プレイヤーにはPhaseを終了させるための行動がある。

Phaseの終了者と終了タイミングはゲーム性を分析するうえで重要な情報であるため、シミュレーションでは必ず記録する。

## ぶら下げ配置

Phase 2以降では、通常の配置に加えてボード端部から駒をぶら下げる配置が可能。

対象となる向きは以下。

* `ZX`
* `ZY`
* `XZ`
* `YZ`

XまたはY方向が下向きになる配置を扱う。

ぶら下げた駒については、下向きの面を下のPhaseのものとして扱う。

重要：

* 下側の面は下のPhaseとして得点計算に参加する
* 同じ面を上のPhaseとして二重に計算してはいけない
* 下側が空いているか、別の駒で占有されているかによって、ぶら下げ可能性を単純に制限しない

この部分は現在の実装を優先する。

## 得点

得点は、ボード上のX/Y/Z方向のラインについて、駒の色などを用いた論理的な判定によって計算する。

具体的な得点判定は現在の実装を正とする。

AIや分析コードでは、得点計算を独自に再実装せず、可能な限り既存のゲームロジックを利用する。

## ゲーム終了

ゲーム終了条件・Phase終了条件は現在のゲーム実装を正とする。

特に以下を区別して扱う。

* 通常の手番
* Phase終了
* 強制的なPhase移行
* 最終的なゲーム終了

## シミュレーション

ゲームを大量に自動プレイし、CSVとして記録する。

現在までに大量対戦による統計分析を行っている。

今後は、

1. Random AI
2. Monte Carlo AI
3. Monte Carlo Tree Search (MCTS)

の順に戦略AIを実装する。

## AI実装方針

AIはゲームルールを独自に持たない。

```text
Game State
    ↓
合法手の取得
    ↓
候補手を適用
    ↓
ゲームを進行
    ↓
勝敗・得点を評価
```

という形で、既存のゲームエンジンを利用する。

AIとゲームルールを分離すること。

推奨構造：

```text
src/
    game.py
    board.py
    piece.py
    ...

ai/
    random_ai.py
    monte_carlo.py
    mcts.py

simulation/
    simulate.py
    analysis.py

tests/
```

実際のファイル構成は現在のプロジェクトを確認してから決定する。

## 分析で特に注目する項目

このゲームでは、単純な最終勝率だけではなく以下を重要な分析対象とする。

* F/Gの勝率
* 最終得点
* 得点差
* Phase 1終了者
* Phase 2終了者
* Phase終了のタイミング
* Phase終了者と勝率の関係
* 各Phaseでの合法手数
* 各手の選択
* 各駒の使用状況
* 盤面状態と勝率
* AIが選択した手とその後の勝率

## Codexへの重要な指示

このプロジェクトでは、ゲームルールそのものが研究対象である。

したがって、既存のルールを推測で変更しないこと。

特に、

* Phase
* ぶら下げ配置
* 得点判定
* 駒の向き
* 手番
* ゲーム終了条件

について不明点がある場合は、既存コードを調査したうえで質問する。

AIを追加する際も、まず既存実装を利用できるか確認する。

既存のゲームロジックとAIロジックを混在させない。

また、既存のシミュレーション結果を再現できる状態を維持する。


# 検証メモ

## 1. 検証方針

まず完全ランダムプレイによってゲームの基本的な性質を把握し、その後、ルール変更による影響を比較する。

ゲームの基本構造が確認できた段階で、戦略AIを導入する。

### 1.1 ランダムプレイによる基本特性の把握

**Random Play vs Random Play**

両プレイヤーが完全ランダムに行動するゲームを多数回シミュレーションし、現在のルールにどのようなゲーム上の特徴・偏りがあるかを調べる。

主に以下を確認する。

* F/Gの勝率・引き分け率
* 先手・後手の有利不利
* Phaseごとの得点差
* Phase終了者と勝敗の関係
* Phase終了までの手数
* 最終的なスコア差
* Phase 1の得点差と最終勝敗の関係
* Phase 1のリードからの逆転率

また、ルールを変更した場合にも同じ実験を行い、各ルールがゲームの性質にどのような影響を与えるか比較する。

---

## 2. 完全ランダムプレイによる基本特性

### 2.1 既存ルールでの1000局

* F勝利: 538 (53.80%)
* G勝利: 349 (34.90%)
* 引き分け: 113 (11.30%)
* 平均スコア差: 0.92
* 最大スコア差: 12
* 最小スコア差: -15
* 平均ターン数: 18.453
* 最小ターン数: 9
* 最大ターン数: 24

Phaseごとの平均スコア差（F-G）は、

* Phase 1: +0.269
* Phase 2: +0.494
* Phase 3: +0.669

となった。

完全ランダムプレイでもF側に一定の先手有利が見られる。

---

## 3. Phase 1終了者と勝者の関係

### Phase 1終了者 × 勝者

| Phase 1終了者 | F勝利 | G勝利 | 引き分け |
| ---------- | --: | --: | ---: |
| F          | 263 | 205 |   48 |
| G          | 283 | 160 |   41 |

### Phase 1終了者ごとの勝率

* FがPhase 1を終了:

  * F勝利: 51.0%
  * G勝利: 39.7%
  * 引き分け: 9.3%

* GがPhase 1を終了:

  * F勝利: 58.5%
  * G勝利: 33.1%
  * 引き分け: 8.5%

GがPhase 1を終了すると、次のPhaseでFが先に行動できるため、Fが有利になる。

この結果から、**Phase終了のタイミングがプレイヤー間の先手・後手差に影響する可能性**が示された。

---

# 4. Phase終了ルールの比較

以下の2種類を1000局ずつ比較した。

* `by_player`: プレイヤーが確率的にPhase終了を選択
* `fixed`: 8手でPhase終了

### 4.1 勝率

| Phase終了ルール  |         F勝利 |         G勝利 |      引き分け |
| ----------- | ----------: | ----------: | --------: |
| `by_player` | 541 (54.1%) | 383 (38.3%) | 76 (7.6%) |
| `fixed`     | 469 (46.9%) | 440 (44.0%) | 91 (9.1%) |

`by_player`ではFの勝率が54.1%となり、F側に明確な先手有利が見られた。

一方、`fixed`ではF 46.9%、G 44.0%となり、両者の勝率がかなり接近した。

したがって、**Phase終了ルールは先手・後手のバランスに大きな影響を与える**ことが分かった。

---

## 5. Phase 1・2の得点比較

### Phase 1

|             |   F平均 |   G平均 | 平均得点差 (F-G) |
| ----------- | ----: | ----: | ----------: |
| `by_player` | 2.685 | 2.257 |  **+0.428** |
| `fixed`     | 2.820 | 2.800 |  **+0.020** |

`by_player`ではPhase 1からFが平均+0.428点有利だった。

一方、`fixed`では平均得点差が+0.020と、ほぼ完全に均衡している。

Phase 1でのリード率も、

* `by_player`: F 47.4%、G 28.3%、同点24.3%
* `fixed`: F 39.6%、G 37.2%、同点23.2%

となっており、`by_player`ではFがPhase 1からリードしやすい。

### Phase 2

|             |   F平均 |   G平均 | 平均得点差 (F-G) |
| ----------- | ----: | ----: | ----------: |
| `by_player` | 7.058 | 6.172 |  **+0.886** |
| `fixed`     | 7.133 | 7.060 |  **+0.073** |

`by_player`ではPhase 2でもFの得点差が拡大している。

一方、`fixed`ではPhase 2でもほぼ均衡している。

## 6. 最終スコア

|              | `by_player` | `fixed` |
| ------------ | ----------: | ------: |
| 平均スコア差 (F-G) |      +0.886 |  +0.121 |
| 最大差          |          15 |      16 |
| 最小差          |         -14 |     -14 |
| Fリード         |         541 |     469 |
| Gリード         |         383 |     440 |
| 同点           |          76 |      91 |

`by_player`では最終的な平均スコア差もF側に偏っている。

一方、`fixed`では平均スコア差が+0.121まで小さくなり、勝率・得点差ともにF/Gがかなり均衡した。

# 7. Phase 1の得点差と最終勝敗

Phase 1終了時点の得点差が、最終的な勝敗に強く影響している。

例えば、

### `by_player`

| Phase 1のF-G差 |   F勝利 |   G勝利 |  引き分け |
| -----------: | ----: | ----: | ----: |
|           -2 | 11.6% | 86.0% |  2.3% |
|           -1 | 24.3% | 67.2% |  8.5% |
|            0 | 45.3% | 43.2% | 11.5% |
|           +1 | 70.4% | 20.0% |  9.6% |
|           +2 | 86.6% |  7.5% |  6.0% |
|           +3 | 90.7% |  9.3% |  0.0% |

`fixed`でもほぼ同様の傾向が見られた。

特に、Phase 1で1点リードしただけで最終勝率が約70%まで上昇し、2点リードすると80%以上となる。

したがって、**Phase 1の得点差は最終勝敗を強く予測する要因になっている**。

---

# 8. 逆転率

Phase 1でリードしていた側が最終的に負ける割合を調べた。

| ルール         | Fリード→G逆転 | Gリード→F逆転 |
| ----------- | -------: | -------: |
| `by_player` |    13.9% |    19.1% |
| `fixed`     |    13.6% |    15.6% |

Phase 1でリードした側は、おおむね80%以上の確率で最終的にも勝利している。

また、リード幅が大きくなるほど逆転率は低下する傾向がある。

### `by_player`

| リード幅 |   逆転率 |
| ---: | ----: |
|   1点 | 21.8% |
|   2点 |  9.1% |
|   3点 |  8.9% |
|   4点 |  4.3% |

### `fixed`

| リード幅 |   逆転率 |
| ---: | ----: |
|   1点 | 22.1% |
|   2点 | 10.3% |
|   3点 |  1.0% |
|   4点 |  5.0% |

3点以上はサンプル数が少ないため細かな数値は参考程度とする。

一方、**1点差では約22%、2点差では約10%という大きな違い**が確認できた。

---

# 9. 現時点での考察

今回の検証から、以下のことが分かった。

### ① `by_player`にはF側への先手有利がある

`by_player`ではPhase 1からFの平均得点が高く、最終的にもF勝率が54.1%となった。

この原因の一つとして、Phase終了のタイミングによって次Phaseの最初の行動権が変化する構造が考えられる。

### ② `fixed`にすると先手・後手の差が大きく縮小する

`fixed`では、

* Phase 1平均得点差: +0.428 → +0.020
* 最終平均得点差: +0.886 → +0.121
* F勝率: 54.1% → 46.9%
* G勝率: 38.3% → 44.0%

となった。

したがって、**現状の2つのルールを比較すると、`fixed`のほうがF/Gのバランスは良い**。

### ③ Phase 1のリードはかなり重要

Phase 1で1点以上リードすると最終勝率が大きく上昇する。

また、Phase 1でリードした側からの逆転率はおおむね10～20%程度であり、**一度ついた得点差は比較的維持されやすい**。

### ④ ただし、現時点では「逆転が少なすぎる」とは判断しない

これはゲームの戦略性と関係するため、ランダムプレイだけでは評価できない。

Phase 1の得点差を後半で覆すこと自体が難しいゲームなのか、それともランダムプレイでもたまたまそうなっているのかは、戦略的なプレイを導入して初めて判断しやすくなる。

---

# 10. 次の段階

ランダムプレイによる基本特性の検証は、ここで一区切りとする。

次は、

**戦略AI vs Random**

に進み、ランダムプレイに対して戦略的な意思決定がどの程度勝率を向上させるかを調べる。

その後、

1. 戦略優位性
2. 意思決定強度
3. 最善手の明確さ
4. 選択肢の多さ

を順に検証する。
